# Lyra 项目官网

使用 React、TypeScript 和 Vite 构建的单页网站，部署到 GitHub Pages。

```bash
npm install
npm run dev
```

生产构建：`npm run build`，输出目录为 `dist/`。

## 发布

仓库的 `Deploy site to GitHub Pages` 工作流会在 `site/` 变更合入 `main` 后自动发布。
首次使用时，在仓库 **Settings → Pages → Build and deployment** 中将 Source 设置为 **GitHub Actions**。

站点地址：`https://sakura-jay.github.io/Lyra-music/`。
