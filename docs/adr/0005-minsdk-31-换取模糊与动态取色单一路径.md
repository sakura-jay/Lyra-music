# minSdk 定为 31（Android 12），换取模糊与动态取色的单一路径

歌词页要求"通透美观"的封面模糊背景与 Material 3 动态取色，而这两项都是 Android 12+ 的系统能力（`Modifier.blur` 底层为 `RenderEffect`，均匀 radius 模糊自 API 31 起支持）。若 minSdk 降到 26/29，就要自维护一条降采样模糊降级链并处理两套视觉一致性。决定 minSdk 直接取 31，让模糊与取色只有一条实现路径。

## 后果

- 放弃 Android 8–11 设备；用户自己的设备若低于 Android 12 将装不上。
- 渐变（空间可变）模糊 radius 需 API 33+，一期不使用，只用均匀 radius。
- 全屏模糊会被强制渲染进独立 graphics layer 并按内容边界 Clip clamp，边缘会出现硬切/暗边，需以降采样封面 + 两层缓存 alpha crossfade 规避，而不是每帧大跨度动画 radius。
