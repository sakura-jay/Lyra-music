# 数据双轨：音源优先，内置适配器降级，取址失败自动换源

音源只提供 `search` / `musicUrl` / `lyric` / `songList` / `leaderboard` 这类 action，且现实中不少音源不实现 `songList` 与 `leaderboard`。决定所有支持降级的数据都以"音源优先、缺失或失败时走内置适配器"的双轨获取；播放取址失败时，用同一首歌的标题与艺术家到其他已启用音源自动换源。

## 后果

- 同一首歌可能来自两个不同供给方，UI 必须打来源标签，去重与匹配规则成为核心逻辑而非边角。
- 内置适配器直连平台接口，会因平台改版失效，因此必须隔离在独立模块、失败静默降级且不阻塞主流程。
- 降级与换源不得静默换内容，用户要能查到本次数据到底从哪来、音质到底降到了哪档。
