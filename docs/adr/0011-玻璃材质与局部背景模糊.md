# 玻璃材质统一，真实背景模糊只用于连续浮层

M11 要在全局建立一致的玻璃质感，同时保留正文、封面和文字的清晰度。决定由主题派生统一的半透明材质、细边缘与控件形态，真实背景高斯模糊只覆盖标准顶栏、底部导航和播放条等少量连续浮层；列表卡片、输入框、按钮与弹窗不各自创建实时采样模糊层。顶栏模糊必须通过覆盖布局与局部背景采样实现，不能对 `TopAppBar` 自身使用 `Modifier.blur`，也不把播放页的全屏 `BlurBackdrop` 复用为通用组件。

## 后果

- 列表不会在滚动时为每张卡片增加独立离屏模糊层，性能风险集中在少量可单独测量的区域。
- 标准页面要把原来的顶部布局留白改为内容 padding，让正文能滚到顶栏后方；首项初始位置保持不变。
- 新增模糊沿用 ADR-0005 的固定半径与降采样原则，并纳入既有真机 Jank 门槛；不达标时减少采样成本或退回半透明材质，不取消性能门槛。
