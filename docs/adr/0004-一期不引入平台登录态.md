# 一期不引入平台登录态（Cookie），评论区因此推到二期

用户要的"查看评论"在现实中必须依赖平台登录态——网易云、QQ 的评论接口如今都不向游客返回真实热评，公开的第三方 API 项目也早已停止维护。要求在设置页粘贴 Cookie 会带来配置负担、过期重填、以及"写回平台"这类敏感接口的高失效率，与一期"先把播放器和歌词页做到最优"的目标冲突。决定一期完全不引入平台登录态，收藏与歌单全部为本地资产，评论整块推入二期。

## 后果

- 一期不出现任何 Cookie/账号设置入口，避免半成品登录态留在 UI 里。
- 需要登录态的数据（真实热评、部分平台的逐字歌词、平台收藏夹写回）在一期一律不做或走退化路径；逐字歌词缺失时歌词页退化为逐行呈现，不作为验收阻塞项。
- 二期若引入登录态，需另立 ADR 说明 Cookie 存储与失效策略。
