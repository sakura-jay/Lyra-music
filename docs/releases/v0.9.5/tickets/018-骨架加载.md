# 018 骨架加载（Kazumi 式 shimmer，自建轻量实现）

## 需求来源

用户点名参考 Kazumi 的骨架加载动画。核实：Kazumi 用的是 `skeletonizer: ^2.1.2`
（pubspec.yaml 实证）。Compose 侧不引第三方，自建 `LyraSkeleton`。

## 规格

- 单块：圆角灰块（`surfaceContainerHighest` 底 + `surfaceContainer` 高光），
  shimmer = 1200ms 循环线性渐变平移（`graphicsLayer` 绘制层，不碰布局属性），
  乘 MotionScale；scale=0 静态灰块。
- 预设三件套：`LyraSkeletonCardRow`（首页两排，110dp 卡形 ×N）、`LyraSkeletonGrid`
  （广场 2×2）、`LyraSkeletonListRow`（列表行"方块+两行字"，SMALL 档 200ms 淡入
  + 40ms 错峰 cap 240ms）。
- 落点：首页推荐排 loading、榜单广场 loading、榜单详情 `songs.isEmpty() && loading`
  时 8 行、搜索 searching 时 3 行。
- 出现条件统一 `items.isEmpty() && loading`：数据一到原位替换，不做内容交叉淡出。

## 验收

- JVM：shimmer 时长换算（1200→600→0）与 stagger cap 两条。
- 模拟器回归绿；真机目视四处落点（弱网/冷缓存才能看到骨架）。
- 真机 PLK110 冷启动榜单详情（`build/walk/a017c/real/` 序列帧）：骨架行随数据
  到达原位替换，行淡入约 2–3 帧完成，无布局跳动（018 的设计目标：数据到达后
  替换不重排）。

## 不做

- 不做 shimmer 速度分级、不做多主题 shimmer 颜色配置、不给骨架加"点击跳过"。
