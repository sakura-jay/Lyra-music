# 状态形变：♥ 与播放 / 暂停

**Blocked by**: 002、004

## 目标

以前这两处都是硬切：♥ 是"点完换一张图"，播放 / 暂停是"点完闪一下"。它们恰恰是用户最常点、
也最需要确认的两个控件，硬切等于没有回答。

## 涉及层

- [x] `ui/common/FavoriteHeartButton.kt`：`border → filled` 交叉淡出（small 档）
  + 0.9 → 1.00 的弹性放大（`DampingRatioMediumBouncy`，380 刚度），点击点带一层 ripple。
  四处共用：播放页顶栏、曲目行尾、歌单封面角（自带一层 32dp 底圆）、歌单详情页顶栏。
- [x] `ui/common/PlayPauseButton.kt`：`AnimatedContent` 图标纵向 slide-through
  （新的从下方进、旧的从上方出，micro 档）+ 按钮 0.92 → 1.00 的 one-shot pop；
  播放页大圆与迷你条小圆共用一份，命中区取 `max(diameter, 48dp)`。
- [x] ui-test：连点 ♥（同一帧内五次）、动画中途反向、播放 / 暂停中途反向，终态必须等于数据状态。

## 数据状态与视觉状态的关系

**真实状态在点击当帧写库**，视觉只表达过渡，不替状态争取时间。相邻的行与卡片**不参与**这次
变化——"收藏一首歌让整列都动一下"是把局部状态说成了全局事件（模式 7 的联动语义在本项目明确不适用）。

## 偏差记录

- **不加常驻呼吸 / 进度环**。常驻动画每帧都要自绘，`CHANGELOG.md` 已实测它把刷新率从 60 拉到
  120，而歌词扫光本身就在画——两个常驻动画源叠在同一页上，要么掉帧要么耗电，换来的只是
  "这个按钮在闪"。稳态不动才是这一版要的效果。这条**偏离**了上一轮"呼吸 / 进度环二选一"的提法。
- **`SavedPlaylistsScreen` 行尾的心不换**：它只有"已收藏"一种状态（点它是移出，状态不留在这一页），
  没有可过渡的另一个状态；而且那页背景是确定的，垫一层底反而显得脏。保留原来的实心 `IconButton`。
- 播放页页码指示器不在这里，见 006。

## 验收标准

- 真机录屏看中间帧：♥ 能看出"实心正在长出来"，播放 / 暂停能看出图标在换位，不是一闪。
  **♥ 这一半已录到**（PLK110 release）：220ms 窗口内 15 帧能看到
  "描边 → 部分填充 → 实心 + 涟漪在后"，再点一次可逆。这是第一次**看见**而不是推断中间帧。
  **播放 / 暂停这一半真机没录**——本轮的录像清单里没有它（`build/walk/p/` 下只有
  `heart` / `heart2` 两段与本片有关）。它的中间帧证据来自模拟器的**像素差分设备测试**
  （`MotionScaleUiTest`，见下面 M10 订正一节），判的是"关掉动画时只画终态图标"，
  与"打开动画时看得出换位"不是同一件事。要补的仍是这一条：**真机录屏看它换位的观感**。
  数与判据强度见 [`../CHANGELOG.md`](../CHANGELOG.md)「真机验收补录」。
- 连点与中途反向不崩、不叠成一串：新的这一轮取消上一轮（`Animatable` 自带互斥）。
- `MotionScaleProvider(0f)` 下两处都到终态，且点击照样生效。**这一条当时没量到，是 M10 补的**：
  原文写的是"当帧到终态"，那是推理而不是实测，而且**两处都推错了**——播放/暂停用的
  `EnterTransition.None togetherWith ExitTransition.None` 会把两个图标同画一帧（按钮闪一下"三角形压在
  两根竖条上"）；♥ 那两张常驻叠图则**晚一帧**才染上实心。
  ♥ 这里补一句订正：中途曾把成因写成"`tween(0)` 仍要先排一次起始值"，并据此改成 `else snap()`——
  **那个修法没让测试变绿，差分数字 1525 一个像素都没动**，所以成因不在 spec。真正的原因是
  `animateFloatAsState` 的目标由协程里的 `Animatable` 追，而协程在本次组合提交之后才跑。
  M10 写 014 时抄了这里，第一条设备测试就红了，回头量才发现两处同源。现在修成"关掉动画就不读
  动画值 / 不进 `AnimatedContent`"，各由一条像素差分测试钉住
  （`playPauseGlyphPaintsOnlyTheEndStateWhenMotionIsOff`、
  `heartReachesTheEndStateOnTheFirstFrameWhenMotionIsOff`，在 `MotionScaleUiTest`）。
  同一条判据后来还抓到第三处：页码指示器的**颜色**（`animateColorAsState`），量到 1130 像素。
  过程与数据见 [`../v0.9.3/CHANGELOG.md`](../v0.9.3/CHANGELOG.md) 的决策 8。
