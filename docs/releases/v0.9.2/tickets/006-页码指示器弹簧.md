# 页码指示器：当前点挤开其余点

**Blocked by**: 002

**主交互**：Expanding Tag Selection（标签挤开，模式 10）。判定理由：这是全应用里唯一一处
"一个元素变宽、周围元素主动让位"的真实落点。

## 目标

播放页两页（封面页 / 歌词页）之间的翻页指示器，从"当前点换颜色"改成"当前点变药丸、其余点让位"。

## 涉及层

- [x] `PlayerScreen.kt` 的 `PageIndicator`：当前点由 **7dp 圆**变 **18dp 药丸**，
  用 `scaleX`（`PILL_SCALE = 0.39f` → 1.0）而不是动画 `size()`；其余点 `translationX`
  让位（**≤ 5.5dp**），邻居不重叠、不跳位。
- [x] 驱动源是 `PagerState.currentPage`。`currentPageOffsetFraction` **本版不接**——页码跟手
  属于翻页连续性，留给 M10（012）。

## 为什么是 scaleX 而不是动画尺寸

ADR-0009 护栏二：动画任何参与布局的属性都会让邻居在动画中途被重新测量，指示器这一行的
`Arrangement` 会跟着抖。`scaleX` 走 `graphicsLayer`，布局尺寸全程是药丸的最终宽度，
其余点靠 `translationX` 让位——它们的位置是显式计算出来的，不依赖测量结果。

## 验收标准

- 模拟器截图 + 真机目视：两页之间来回翻，药丸平滑变宽，其余点被挤开但不重叠、不跳位。
  **真机已录到中间帧**（PLK110 release，`build/walk/pager.mp4`）：12 帧竖条显示药丸收窄 /
  圆点变宽是**连续**变化的，高亮身份在中点交换，全程没有重叠、没有整条指示器平移。
  数见 [`../CHANGELOG.md`](../CHANGELOG.md)「真机验收补录」。
- 快速来回翻页不出现"两个点在同一个位置"或指示器整体位移。
  同一段录像里来回翻各一次，未出现。
- **不写语义断言**：形变发生在 `graphicsLayer` 上，语义树看不到中间态（讨论了"瞬时到终态"
  这一条的可断言性，结论是不可断言）。这条由 JVM 时长表 + 真机目视负责。

## M10 期间的订正：颜色这一档当时漏了，而且有真 bug

"不可断言"那句对**形状**成立，但那一点里其实有两个来源不同的东西：`scaleX` / `translationX`
是绘制期从 `currentPage` 现算的（不是动画插值），**颜色却是 `animateColorAsState(tween(...))`**。
按"关掉动画不许读动画值"去量它，第 0 帧与第 1 帧差 **1130 像素**——也就是关掉系统动画之后，
药丸的形状当帧到位、颜色要晚一帧才染上。修法与前几处同一形状：`shouldAnimate` 为假时直接取终色。

现在由 `MotionScaleUiTest.pageIndicatorLandsOnTheEndColourOnTheFirstFrameWhenMotionIsOff`
钉住。过程与另外两处（005 ♥、005 播放/暂停）同源，见
[`../../v0.9.3/CHANGELOG.md`](../../v0.9.3/CHANGELOG.md) 的决策 8。
这一条同时说明：**"这一处看不出中间态"不等于"这一处没有中间态"**——形状看不出，颜色看得出。
