# 025 顶栏与连续浮层模糊

## 目标

让标准顶栏、底部导航和播放条模糊其背后的内容，标题、图标与正文始终清晰。

## 实施

- 顶栏改为覆盖层；原顶部布局留白转成滚动内容的 `contentPadding`，首项位置不变。
- 背景宿主为顶栏区域提供降采样副本，固定半径做局部 `RenderEffect`；效果层
  与前景分离。不能直接给 `TopAppBar` 加 `Modifier.blur`。
- 先打通首页或榜单广场的一条滚动链，再覆盖其余标准 `TopAppBar` 页面。
- 底部导航和播放条复用同一采样约束；播放页沉浸顶栏与系统状态栏单独处理。
- 无背景重叠或性能不达标时退回 024 的半透明材质。

## 验收

- 内容连续滚过顶栏时有可见模糊，无硬切、暗边、首项跳动或滚动到底异常。
- 标题/图标清晰，正文和封面截图像素区域不被误模糊。
- 复用真机 framestats：原 Jank 场景保持 `< 1%`，新增顶栏滚动 A/B，同时报告
  8.33ms 与 16.67ms 口径；必要时用 Perfetto 归因，不凭单次 p50 下结论。
