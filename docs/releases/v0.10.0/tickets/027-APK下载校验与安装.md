# 027 APK 下载校验与安装

## 目标

点击更新后在应用内可靠下载 APK，验证其身份并交给 Android 系统安装器。

## 实施

- 下载使用可跨页面/后台持续的工作管理组件；Wi-Fi 与移动网络均允许，只有
  用户点击更新才启动。更新弹窗展示百分比、取消、失败原因与重试。
- 写入应用缓存临时文件，完成后原子重命名；重复下载停掉旧任务，旧文件在
  新下载或正常退出时清理，避免部分文件被当成安装包。
- 用系统包解析校验 APK 包名、目标版本与签名证书；包名不符、损坏、降级或
  签名与当前安装不一致时拒绝安装并显示原因。
- 配置缓存专用 `FileProvider`、`REQUEST_INSTALL_PACKAGES` 和未知来源引导；
  最终调起系统安装确认页，不把“已打开安装器”误报为“安装成功”。
- 安装器返回后重新读取当前版本决定状态，不假定用户已确认安装。

## 验收

- 下载中切页面/后台进度不丢；取消不残留可安装任务，失败可重试。
- 断流、空间不足、404、损坏 APK、包名/版本/签名不符均有确定终态。
- 真机验证未知来源授权、系统确认、取消安装与签名一致的覆盖安装。
- 更新不清除用户设置与音乐资产，成功后版本显示与再次检测结果正确。
