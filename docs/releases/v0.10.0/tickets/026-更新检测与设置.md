# 026 更新检测与设置

## 目标

以 GitHub 最新正式 Release 为唯一更新元数据来源，打通自动/手动检测、
更新日志、关闭与忽略版本。

## 实施

- 用现有 OkHttp/协程访问官方 HTTPS API，设置合理超时与整体取消；只接受
  非 draft、非 prerelease 的 `vX.Y.Z`，严格更高才提示。
- 从 Release assets 选择 APK，保存目标版本、日志和下载信息；缺失 APK 是明确错误。
- 建立统一更新状态机：空闲、检测中、最新、有更新、失败；自动与手动入口共用。
- 冷启动首屏可交互后检测一次，自动失败静默；页面切换/回前台不重复触发。
- 设置新增“关于与更新”：当前版本、默认开启的自动检测开关、手动检查按钮。
- `SharedPreferences` 保存开关和精确忽略版本；关闭下次仍可提示，手动检查
  忽略版本仍显示，更高版本重新提示。
- 更新弹窗滚动展示目标版本日志，支持基本 Markdown 与链接；按钮为更新、关闭、
  忽略此版本。027 接管下载状态。

## 验收

- 单测覆盖版本三段比较、无效标签、相同/更低版本、忽略与手动检测语义。
- MockWebServer 覆盖最新、无更新、草稿/预发布、缺 APK、超时、限流与坏 JSON。
- 自动检测不阻塞首屏且失败不弹窗；手动检测展示最新或可理解的错误与重试。
- 开关和忽略状态重启后保留，同一启动最多自动弹一次。
