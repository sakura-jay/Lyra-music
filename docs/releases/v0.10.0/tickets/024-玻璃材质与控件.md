# 024 玻璃材质与控件

## 目标

建立全局可复用的玻璃材质 token 和容器，统一输入框及主要/次要按钮，
不先引入真实背景模糊。

## 范围

- 在主题层定义半透明表面、边缘高光/分隔线、圆角与内容色，零硬编码浅灰。
- 提供玻璃卡片/弹窗容器；接入歌曲、歌单、榜单、音乐库入口与设置区块。
- 统一文本输入框及主要/次要按钮，参考图的大圆角和柔和填充；保留图标按钮。
- 保留选中、按下、禁用、错误、搜索高亮等语义和现有动效缩放契约。

## 不做

- 不给正文、封面、歌词加模糊，不增加外观设置项。
- 不强迫无底色的 `PlaylistCard` 变成厚重容器；材质不得破坏现有信息密度。

## 验收

- 四组主题截图，主要页面视觉一致，文字与控件状态可辨。
- 输入、搜索、导出/导入、清除缓存等原交互不回归。
- 无真实模糊时已具备完整可回退的玻璃外观。
