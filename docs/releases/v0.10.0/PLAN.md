# v0.10.0 计划（M11：玻璃材质与应用内更新）

一个里程碑、四个垂直切片。视觉材质与应用内更新可分别验证、分别回退；
版本权威仍是 tag，APK 与更新日志沿用现有 GitHub Release 发布链。

## 已确认边界

- 玻璃材质覆盖标准顶栏、底部导航、播放条、卡片、输入框、按钮与弹窗；
  正文、封面和歌词保持清晰，不做整页模糊。
- 真实背景模糊只用于标准顶栏、底部导航和播放条；卡片等独立控件只做
  半透明材质与细边缘，不逐卡片采样。播放页沉浸顶栏单独适配。
- 输入框和按钮按参考图采用大圆角、柔和填充、弱边框与轻量层级；图标按钮
  保留现有形态。材质跟随明暗、动态取色和预设主题，不新增玻璃强度设置。
- 冷启动且首屏可交互后检测一次；默认开启自动检测，失败静默。手动检测
  始终可用，并明确展示最新、失败与重试状态。
- 只读 GitHub 最新正式 Release，按 `vX.Y.Z` 与当前 `versionName` 比较；
  排除草稿和预发布，不使用多镜像或明文回退。
- 弹窗展示目标版本 Release 日志。关闭只关闭本次，忽略只抑制该版本的自动
  弹窗；手动检测不受忽略影响，更高版本重新提示。
- 点击更新才下载，Wi-Fi 与移动网络均允许；下载有进度、取消、失败重试，
  切后台可继续。下载后校验 APK，再调起系统安装确认页，不承诺静默安装。

## 实施顺序

1. 024 先建立材质与控件基线，保留无真实模糊的视觉回退能力。
2. 025 在一条滚动页面验证局部采样，再推广到标准顶栏和连续浮层。
3. 026 打通检测到提示与设置的完整链路，下载入口暂由 027 接管。
4. 027 完成下载安装与供应链校验，最后统一做视觉、更新和性能收口。

## 合入即验证

- `:app:testDebugUnitTest`、`:app:lintDebug` 全绿；新增状态机与解析测试齐备。
- 相关 Compose 仪器测试通过；更新网络测试不依赖真实 GitHub。
- 浅色/深色 × 动态/预设主题截图：材质一致、正文清晰、文字可读。
- 真机 release 包：列表/广场滚动与转场首帧 Jank 保持 `< 1%`；新增顶栏
  连续滚动 A/B，报告忙帧成本、GPU p50 和超预算数，不以整窗指标代替。
- 真机验证自动/手动检测、关闭/忽略、后台下载、取消/重试、未知来源引导、
  签名一致覆盖安装；损坏、降级、包名或签名不符的 APK 均被拒绝。
