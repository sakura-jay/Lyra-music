# 023 Tab 切换与返回重做

## 问题

1. **切 Tab 闪一下白色返回动画**：底层导航把"切 Tab"当一次 push + pop，被切走的
   旧 Tab 走 `popExit`。此前那条路播的是详情页返回动画（10% 右滑 + 淡出），两页
   交叠处的透明瞬间露出窗口白底。用户看到的就是"切到首页闪一下白色返回动画"。
2. **详情页返回读起来是"半途而废"**：退出只有 10% 的微滑配淡出。淡出会在两页
   之间露出透明（浅色主题即白底），微滑的幅度又不足以表达"离开这一页"。
3. **详情页之间返回时下层重播入场**：Tab 注册处已有 `isDetail(initialState) →
   EnterTransition.None`，但 `lyraDetailRoute` 统一注册处没有。歌单广场 → 具体
   歌单 → 返回时，下层广场页重播了一次滑动入场，两页同时动。
4. **迷你条"蹦出来"**：bottomBar 挂在 `Scaffold` 插槽上，靠 `if (route != PLAYER)`
   直接出现/消失，没有转场；返回详情页时条先蹦出来、内容还在滑。

## 修法

- `LyraMotion` 拆出四条职责明确的转场：
  - `slideIntoTab(scale, forward)`：Tab 之间定向滑入（按 Tab 序号判断方向），
    `NoBouncy` 弹簧 + 60ms 淡入（`DETAIL_FADE_MS`）。被切走的旧 Tab 由
    `LyraApp` 定住不动，入场页从满 alpha 的旧页上淡入，白底没有露出机会。
  - `slideOutToRight(scale)`：详情页整个向右划走，时长取 ROUTE 退出档
    （240ms）配 `FastOutLinearInEasing`，**刻意不带淡出**。
  - 删除 `slideOutOf`（forward 布尔参数一并删除）与 `slideUnderDetail`。
  - `collapseToBar` 的位移/缩放收紧到 120ms（`ROUTE_MOVE_FAST_MS`），淡出仍
    走 160ms + 60ms 延迟，去掉"页面还在慢慢收"的拖尾。
- `LyraApp`：
  - 详情页 `popEnterTransition` 一律 `EnterTransition.None`——底页本来就在原位，
    任何来路下都不再播入场；`popExitTransition` 用 `slideOutToRight`。
  - Tab 页 `exitTransition` / `popExitTransition` 一律 `ExitTransition.None`，
    `popEnterTransition` 也定为 `None`。
  - bottomBar 抽出 `BottomBarWithTransitions`，用 `AnimatedVisibility` 做
    140ms 淡入 + 1/3 高度位移。
  - `showBottomBar = LyraRoutes.isTab(currentRoute)`：迷你条与导航栏只属于三个
    Tab，详情页两者都不出现。
- `LyraRoutes` 新增 `isTab()`，与既有 `isDetail()` 对称。

## 取舍

- **详情页不再有迷你播放条**（本轮明确决定）。此前 `722dcb0` 曾因"详情页点了歌
  没有入口回播放页"而把条加回详情页；本轮改为结构上让 bar 只属于 Tab 层，详情页
  压在它上面，视觉上条随页面 pop 同步出现。这是有意的行为变更，不是回归遗漏。
- 详情页返回不带淡出，两页之间没有透明瞬间，但代价是返回时的位移读起来更"硬"。
  如果真机上觉得过刚，调 `slideOutToRight` 的 easing 而不是加回淡出。

## 验收

- JVM：`:app:compileDebugKotlin` + `:app:testDebugUnitTest` 绿（146 tests）。
- 真机待验：
  - 三个 Tab 来回切，任意方向都不出现白底闪帧；
  - 详情页返回是整页右滑，底页（Tab 或上层详情）定在原位、不重播入场；
  - 顶部播放页展开/收起时 mini 条随 bottomBar 平滑进出，无"蹦出"；
  - 详情页内点歌仍能播放（入口从迷你条变为返回 Tab 后使用）。
