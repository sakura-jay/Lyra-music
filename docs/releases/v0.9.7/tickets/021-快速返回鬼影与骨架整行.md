# 021 快速返回鬼影 + 骨架整行同构（用户两段视频复检）

## 问题（视频逐帧坐实）

1. **快速返回鬼影（视频 1）**：`飙升榜` 详情快速返回首页时，f158–f160（约
   5.23–5.27s）出现 1–2 帧"详情页浮在首页上"的半透明叠影。机制读码对上了：
   019 给 tab 页加的 60ms 微淡出（`slideUnderDetail`）与详情页侧的 popExit
   淡出叠加，而底下的 `popEnterTransition = None` 只在整条 pop 动画结束才提交
   满 alpha——快速返回时底页整段停在半透明。019 的入场淡入修复依赖"底页
   始终满 alpha"这个前提，本版把它撤掉之后那个前提才真正成立。
2. **骨架形状不对（视频 1/文字反馈）**：020 的 `LyraSkeletonRankRow` 是
   "序号条 + 两行字 + 右侧点"三块拼盘，真实 `TrackRow` 是一整行 16dp 边距的
   内容，参考样式（视频 2）是"整行一条完整圆角占位块"。
3. **shimmer 不对（视频 2）**：020 版每块各自起一个 `rememberInfiniteTransition`，
   相位互不同步，渐变带固定 0.5 步长在整行块上不成"一道亮带"；参考视频是
   **页面级一道亮带同步扫过**（约 1.2s 一回）。

## 修法

- `LyraMotion.slideUnderDetail` 回滚为 `ExitTransition.None`：底页必须与
  `EnterTransition.None` 成对，进场淡入只对 push 侧可见性负责，不反向牺牲
  pop 侧的底页。`DETAIL_FADE_MS`（60ms）保留在详情页入场侧。
- 骨架行收敛为 `LyraSkeletonRow`：整行一块，内容高 38dp（与 `TrackRow` 的
  文字列同高）+ 上下 6dp 行 padding，数据到达后原位替换、页面不跳动。
  `LyraSkeletonRankRow` / `LyraSkeletonTextRow` 移除（搜索、榜单、歌单详情
  三处调用点同换）。
- shimmer 改为页级同步扫光：`ProvideSkeletonShimmer(active)` 在页面层提供
  一个 `phase ∈ [-1, 2]` 的无限动画，区内所有块共享同一相位；扫光带宽度 =
  块宽的 1/3（`skeletonShimmerSpan`），随块宽缩放；相位只在 drawBehind 的
  绘制期读取，不进重组。没包 provider 或系统动画关闭时退化为静态灰块，
  详情页在数据到位后以 `active = false` 收掉无限动画。

## 验收

- JVM：`LyraSkeletonTest.shimmerBandScalesWithBlockWidthAndStaysOutsideAtEnds`
  钉"带子随块宽缩放、两端不出块外"；`skeletonRowMatchesTrackRowGeometry`
  钉 38dp 同高；`:app:compileDebugKotlin` + `:app:testDebugUnitTest` 绿。
- 真机：快速往返（进详情后 <300ms 返回）不再出现 1–2 帧半透明叠影；
  弱网进榜单/歌单详情，骨架为整行块、一道亮带同步扫过，数据到达原位替换。
