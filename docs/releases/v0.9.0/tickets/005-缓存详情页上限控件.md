# 缓存详情页「上限」控件 + 持久化 + 调低即淘汰提示

**Blocked by**: 004

## 目标
用户在缓存详情页顶部就能改上限：预设芯片 + 自定义滑块，改完立即生效并（调低时）看到「已释放 X」。

## 涉及层
- [ ] UI 层：`CacheScreen` 顶部新增「上限」段——芯片 128MB / 256MB / 512MB / 1GB / 2GB + 「自定义」滑块（64MB–4GB）；当前上限对应项呈选中态；调低后提示。
- [ ] 逻辑层：`SettingsViewModel` 暴露 `cacheLimit` + `setCacheLimit`（调 `LyraCache.setLimit` 并刷新统计）。
- [ ] 文案层：`settings_cache` 文案里的上限数字改为动态；`cache_hint` 里"上限 128 MB"改为反映可调。
- [ ] 测试：设备测试——选芯片 / 拖滑块 → 上限变更；调低触淘汰并提示；重开应用保持。

## 验收标准
- 缓存详情页顶部可见「上限」段，芯片与滑块均可操作。
- 选预算档 → 立即生效；拖到非预算值 → 「自定义」呈选中。
- 调低到占用以下 → 条数 / 总字节当场变小 + 提示「已释放 X」。
- 设置页「存储」段显示当前上限（非硬编码 128）。
- 重开应用后上限保持。
