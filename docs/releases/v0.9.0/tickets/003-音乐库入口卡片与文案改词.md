# 音乐库入口卡片 + 段落重排 + 文案改「我喜欢」

**Blocked by**: 002

## 目标
音乐库最上方出现「我喜欢 · N 首」卡片，点击进 002 的页面；库内不再内联单曲；全应用"歌曲入库"文案改为「我喜欢」。

## 涉及层
- [ ] UI 层：`LibraryScreen` 移除内联收藏曲目列表，改顶部卡片入口（带 ❤，显示「我喜欢 · N 首」；N=0 时给空态引导）；段落顺序改为 我喜欢 → 我的歌单 → 收藏的歌单 → 本地音乐。
- [ ] 文案层：`strings.xml` —— 歌曲语境 收藏 → 我喜欢（`library_favorite` / `library_count` / `library_empty`、播放页 ♥ 读屏标签等）；`LibraryViewModel` 等提示"已加入收藏 / 已移出收藏" → "已加入我喜欢 / 已移出我喜欢"。**歌单语境保持"收藏"**（`library_favorite_playlists` 等不动）。
- [ ] 数据层：无。

## 验收标准
- 音乐库第一屏看到「我喜欢 · N 首」卡片；收藏为 0 时有空态引导，不出现"计数为 0"的怪异态。
- 段落顺序符合；我的歌单 / 收藏的歌单 / 本地音乐不再被单曲长列表挤到屏幕外。
- 全应用检索"收藏"只出现在歌单语境；歌曲语境一律"我喜欢"。
- 空态、提示、读屏标签同步改到。
