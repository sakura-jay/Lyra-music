# 封面图片缓存 / 去重 / 降采样 + 榜单广场 Jank 验收

**Blocked by**: 009

## 目标
榜单广场滚动流畅：封面不重复解码、并发请求去重、按卡片尺寸降采样；Jank < 1%。

## 涉及层
- [ ] 逻辑层：`ArtworkLoader` 增强——**解码位图 LRU 缓存**（当前 `rememberRemoteArtwork` 无，滚出列表即丢、回来重解）+ **同一 URL 并发请求去重**（in-flight 合并）+ 按目标尺寸降采样（已有 `decodeDownsampled`）。`rememberRemoteArtwork` 走后端缓存。
- [ ] UI 层：榜卡片统一走该入口。
- [ ] 测试：设备测试——同一 URL 并发仅一次下载；封面滚出再滚回复用（缓存命中）；Jank（`gfxinfo framestats` 新指标）< 1%。

## 验收标准
- 同一封面滚出再滚回**不重复解码**（Bitmap 缓存命中）。
- 同一 URL 并发仅一次网络请求。
- 榜单广场滚动 Jank < 1%（与歌单广场同量级）。
- 缓存有上限，不因图片加载引入无界内存增长。
