# 「我喜欢」页端到端

**Blocked by**: 001

## 目标
能从导航进入「我喜欢」页：看到全部已收藏曲目，点歌即播（队列 = 整个列表），点行内 ♥ 移出，行尾「更多操作」可用。

## 涉及层
- [ ] 数据层：复用 `FavoritesRepository`（`favorites` StateFlow / `toggle` / `keyOf`）。无 schema 变更。
- [ ] 逻辑层：新增 `LikedRoute`，仿 `MyPlaylistRoute`（`TrackListRoutes.kt`）——`TrackListViewModel.factory` 注入 loader（`favorites.refresh()` 映射为 `TrackList`）；观察仓库计数变化触发 `reload()`；行内 ♥ 调 `favorites.toggle` 后刷新。
- [ ] UI 层：`TrackListScreen` 增加"行内 ♥"转发口（新参数，把 `TrackRow` 已有的 `favorite` / `onToggleFavorite` 透下去，`TrackRow.kt:53-54,117-126`）；导航注册 `ROUTE_LIKED`（`LyraApp.kt`）。
- [ ] 测试：设备测试——进页显示收藏；点 ♥ 移出后行消失且音乐库入口计数 -1；点歌进播放、队列为该页全部曲目。

## 验收标准
- 新增路由能进「我喜欢」页，头部显示"我喜欢" + 曲目数。
- 点任一行 → 播放，播放队列 = 该页全部曲目（收藏时间倒序）。
- 点行内 ♥ → 该曲移出、行消失、不跳出页面。
- 点行尾 ⋯ → 打开"放去哪儿"选择器（应用级 `PlaylistPickerViewModel`）。
- 该页**不出现**"顶部整列表收藏"心形（那是平台歌单页的形状）。
