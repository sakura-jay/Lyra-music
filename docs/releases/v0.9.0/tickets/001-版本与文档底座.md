# 版本与文档底座：根 CHANGELOG 转总索引

**Blocked by**: 无

## 目标
把"每版本一个目录"的文档约定落地：本版有地方记 changelog，根 `CHANGELOG.md` 成为总索引，M0–M7 历史不丢。

## 涉及层
- [ ] 文档层：根 `CHANGELOG.md` 顶部加「版本索引」，能一眼找到各版本位置；`[Unreleased]` 一节改为"新版本见 `docs/releases/`"的说明（新版本明细不再写进根文件）。
- [ ] 文档层：确认 `docs/releases/v0.9.0/{PLAN.md, CHANGELOG.md}` 就位（本轮已建）；M0–M7 历史原地保留在根文件，不迁移。
- [ ] （无代码层）

## 验收标准
- 根 `CHANGELOG.md` 顶部有版本索引，能定位 v0.9.0 的计划与 changelog。
- M0–M7 历史内容仍在根文件可查。
- 约定与 `CONTEXT.md` 的「开发分支 / 里程碑」条目呼应（一个里程碑一 minor；每版本一目录；1.0 为终点）。
- 约定：**新增版本记录一律落 `docs/releases/vX.Y.Z/CHANGELOG.md`**。
