# 音乐库全部改为入口卡片 + 我喜欢封面

**Blocked by**: 003（验收时发现：入口卡片只给了我喜欢，其余三段仍是内联列表，风格不统一）

## 目标
音乐库只剩四张入口卡片——我喜欢 / 我的歌单 / 收藏的歌单 / 本地音乐，各自点进列表页；
我喜欢页与卡片用最近添加那首歌的封面，不再是 `♪` 占位。

## 涉及层
- [ ] UI 层：`LibraryScreen` 去掉内联列表与小节标题，改四张 `LibraryEntryCard`（封面/图标 + 名称 + 数量）；
      未授权时「本地音乐」卡片保留尾部「授权」按钮，已授权保留「重新扫描」。
- [ ] UI 层：新增 `MyPlaylistsScreen`（我的歌单列表：点击进入、长按改名/删除、顶栏新建）与
      `SavedPlaylistsScreen`（收藏的歌单列表：点击进入、行内 ♥ 移出）。`PlaylistRow` /
      `SavedPlaylistRow` / `NameDialog` / `PlaylistManageDialog` 随迁到这两个文件。
- [ ] 逻辑层：`LikedRoute` 的 `TrackList.coverUrl` 取 `saved.firstOrNull()?.song?.artworkUrl`
      （收藏列表按 `added_at DESC`，第一行即最近添加）；`LibraryScreen` 用同一张图作卡片封面。
- [ ] 导航：注册 `my-playlists`、`saved-playlists` 两条详情路由（进出不带动 Tab）。
- [ ] 数据层：无 schema 变更；`LibraryViewModel` 现有字段与动作全部复用。
- [ ] 测试：无自动化（项目无 Compose UI 测试基建）；编译 + JVM 套件绿；行为待设备侧手动验。

## 封面取值
- 我喜欢 → 最近添加那首歌的封面
- 收藏的歌单 → 第一张收藏名片的封面
- 本地音乐 → 第一首本地曲的封面（本地文件常带内嵌专辑图）
- 我的歌单 → 自建歌单没有封面，取列表图标
- 任一封面取不到 → 退回各卡片的图标，不留纯色空块

## 验收标准
- 音乐库只有四张卡片，无内联曲目/歌单列表；每卡片显示名称 + 数量（为 0 时显示简短空态，不显示"0 首"）。
- 点「我的歌单」进列表页，可新建、可点进、可长按改名/删除。
- 点「收藏的歌单」进列表页，可点进、可行内 ♥ 移出。
- 点「本地音乐」进本地曲页；未授权时卡片上有「授权」入口。
- 「我喜欢」页头部显示最近添加那首歌的封面；新收藏一首后封面随之更新。
