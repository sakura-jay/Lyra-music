## 019 的核实结论（视频实测，1560 帧）

- 用户录屏 3.6s–4.1s（mini 条返回）与 16.1s–16.4s（榜单详情返回）：回程封面
  **飞完了 240ms 全程**（几何轨迹正常），但落点那一刻卡片还没淡入——
  f1315–f1320 连续 5+ 帧"封面已消失、落点空洞"，f1321 迷你条封面才出现。
  017 只对齐了**位移时长**，落点可见性由另一条 180ms+20ms 延迟的入场淡入决定，仍晚。
- 页面退场（spring，无固定时长）比 240ms 飞行长：详情页 f316–322 还在滑、
  播放页 popExit 也拖到 ~40 帧。"封面先消失、页面还在动"的观感由此而来。
- 修法（ADR-0009 的 280/240 位移数值不动）：tab ↔ 详情入场淡入 180+20ms → **60ms 无延迟**；
  tab 页被详情压住时的 `ExitTransition.None` → **60ms 微淡出**对称；飞行本体与曲线不动。

## 020 的核实结论

- **歌单详情（TrackListScreen）此前没有任何列表骨架**：018 的四处落点不含它，
  用户看到的是页头一个小转圈 + 页面空白，"覆盖不全"由此而来。补 8 行整行骨架，
  出现条件与既有约定一致（`loading && list == null`）。
- **榜单/搜索行的骨架前置 44dp 方块是错的**：`TrackRow` 与 `SongRow` 都是纯文字行
  （序号/标题/副行/菜单），没有图片。拆 `LyraSkeletonRankRow`（序号条+两行字+右点）
  与 `LyraSkeletonTextRow`（纯两行字），不再有"突兀的方块"。
- **shimmer 没有动画感**：018 版 highlight = `surfaceContainer`，与底色只差一档且
  渐变带过宽，扫光在浅色主题下肉眼不可辨（用户原话"只有骨架没有动画"）。
  改为按底色亮度推导高光（浅色往白推 65%、深色推 16%），渐变带收紧到 0.5 步长。

## 硬约束（沿用）

- ADR-0009：路由位移 280/240 不动（ADR 已补一节，说明"淡入不属于位移数值"）。
- ADR-0010：共享元素契约不动；019 只动页面自己的入场透明度时序。
- Jank 硬门槛 <1% 只看滚动与转场首帧；骨架与微交互不参与。

## 验证

- JVM 新增 2 条：`landingFadeCompletesBeforeFlightLands`（落点淡入早于封面落地）、
  `highlightIsBrighterThanBaseInBothThemes`（两主题高光都比底色亮）。
- 模拟器 instrumented 全量回归绿；`lintDebug` 0 error。
- 真机 PLK110 装 release 包目视：mini 条快速返回、榜单详情快速返回、四处骨架。
